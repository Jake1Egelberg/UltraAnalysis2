UltraAnalysis is an online analysis tool for sedimentation equilibrium analytical ultracentrifugation data developed by Jacob Egelberg in Dr. Kathryn Ferguson's lab at Yale. The application enables rapid selection of sector fitting ranges and adapts biophysical models from the HeteroAnalysis Software for Sedimentation Equilibrium Analysis (RRID:SCR_014991) for Kd estimation.  

To access the tool, see: https://jake1egelberg.shinyapps.io/UltraAnalysis/
